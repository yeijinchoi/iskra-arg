## 2. 확정된 핵심 설정

- **구도:** 일제 치하 조선(A)-일본(B)-중국(C) 관계를 닮은 3국. 시대는 **현대**. 세계는 지구와 비슷하지만 다른 독자 세계 — A/B/C만 깊게 설계, 나머지 국제사회는 현실과 비슷하게 흐릿한 배경.
- **국가명(유럽/슬라브풍):** A=**바르네시아**(조선형, B 통치하 피지배국) / B=**케스테를룬드**(일본형, A를 직접 통치하는 지역 강대국) / C=**도렌그라드**(중국형, B와 체급 대등한 대륙 강대국, 주인공이 사는 곳)
- **B의 A 통치 방식:** SF적 과장 없이 **평범한 현대 수준** — 언론 통제, 인터넷 일부 검열(특정 사이트·SNS 차단), 통행증/출국 허가제, 정보원을 통한 감시, 집회·결사 제한
- **B-C 관계:** 체급 대등 + 무역·공급망 상호의존 때문에 정면충돌 회피, 외교전·제재전으로 긴장 해소. B는 C에 체류하는 A 출신 활동가에 대해 공식 항의는 계속함
- **C-B 관계:** C는 B를 전략적으로 경계, A 출신 활동가를 비공식 묵인(국경 접경지역 단속 느슨)
- **타임라인(초안, 숫자 조정 가능):** −45년 B의 A 흡수 → −23년 A 대봉기 실패(이후 저항 무게중심이 국외로 이동) → −22~−18년 다수가 C로 탈출·정착(주인공 1세대 부모 포함) → 현재 주인공은 C 출생 2세
- **게임 기본 동기 구조:** B 정보요원이 C 거주 바르네시아계 2세 주인공에게 접근 → 고액 보상 걸고 정보수집 임무(C에 기반 구축 후 A로 돌아가 봉기 일으킬 독립운동가 정보 수집) → 주인공이 활동가들에게 감화 → 엔딩 선택(돈 vs 활동가를 눈감아 줌)
- 상세는 [01_국가설정.md](01_국가설정.md) 참고.

- **중요 서사 규칙(확정):** 주인공은 자신이 받는 의뢰가 바르네시아 독립운동가에 관한 조사라는 사실을 **모른다.** 정보요원(D&K 리서치 그룹 위장)은 항상 정치색 없는 중립적 명목(예: "불규칙 거래 확인")으로 임무를 포장함 — 플레이어는 단서를 스스로 연결해 눈치채야 하고, 주인공 캐릭터가 명시적으로 "독립운동"이라는 단어를 듣는 일은 없어야 함. 모든 의뢰 이메일·NPC 대사를 쓸 때 이 규칙을 지킬 것.

### 미정 (다음 결정 필요)
1. 타임라인 숫자 최종 확정
2. C국 내 A인 거주구 도시명·구체적 지리
3. B국 정보요원의 소속/정체 — 위장 신분 "D&K 리서치 그룹"(리서치 회사), 1차 의뢰까지는 구현 완료(아래 4번 섹션). 정보요원 본인의 정체·소속은 아직 미정
4. 독립운동가 측 핵심 인물(들) — 주인공이 감화되는 대상. 아직 등장 안 함
5. 주인공 신상 — 이름 **레나 소린**(가안, 변경 가능), 도렌그라드 국립대학교 재학 + 카페 소베크 아르바이트, 어머니 "마리야 소린"(바르네시아어 사용). 확정 아님
6. 엔딩 분기의 구체적 조건과 결과
7. 1차 의뢰(라덴통상 반출목록 사건) 이후 전개 — 정보를 찾아 회신하면 어떻게 되는지 아직 미구현

## 3. UI/게임 구조 (실제 빌드 기준)

`사이트/검색엔진.html` **한 파일**이 게임 전체다. 여러 개의 별도 HTML 파일로 사이트를 나누면 아티팩트 환경에서 iframe이 막혀 있어 "실제 여러 탭을 오가며 계속 확인" 하는 느낌을 낼 수 없었음 — 그래서 **공유 브라우저 크롬(탭스트립 1개+주소창 1개) 안에 패널 3개를 넣고 탭으로 전환하는 멀티탭 SPA** 구조로 만듦. 각 패널은 숨겨져도 DOM에 남아있어 상태(안읽은 메일, 로그인 상태, 검색/필터 상태 등)가 탭을 오가도 유지됨.

- **패널 1 — 이스크라 검색 (`#panel-search`)**: 게임 시작 화면. 다음(Daum) 포털 구조 참고, 뉴스 카테고리 탭, 실제로 동작하는 검색(일반 검색어는 "결과 없음", 특정 거래처명을 검색하면 `HINTS` 배열의 힌트성 기사가 뜸 — 아래 참고). 사이드바의 "레나 소린 · 이스크라 메일 열기" 카드가 메일 패널을 새 탭으로 염.
- **패널 2 — 이스크라 메일 (`#panel-mail`)**: 다음 메일을 본뜬 구조. 받은메일함(배경용 읽은 메일 7통)/스팸메일함(3통) 등. 페이지 로드 5초 후 토스트+정보요원 메일(`NEW_MAIL`) 도착 → 열어서 "답장" 누르면 4초 뒤 `ASSIGNMENT_MAIL`(라덴통상 ERP 접속 정보 포함) 도착. 어시그먼트 메일 속 사이트 주소 링크를 누르면 라덴통상 ERP가 새 탭으로 열림.
- **패널 3 — 라덴통상 ERP (`#panel-raden`)**: 의도적으로 이스크라와 다른 팔레트(그래파이트+틸, `#panel-raden` 스코프 CSS 변수로 분리)를 쓰는 "다른 회사의 내부 시스템" — 로그인 게이트(`audit_temp7` / `Rd7!temp`) → 대시보드/**반출목록**. 반출목록은 `genRecords()`가 시드 고정 PRNG(mulberry32)로 **최근 1년치(약 75건 이상)**를 생성 — 공산품/식품/농산물 카테고리를 섞고, 농산물은 쌀·밀·보리·옥수수·감자를 비슷한 평시 수량대로 반복시켜 두고, 그 안에 쌀만 수량이 비정상적으로 큰(평시 대비 10배 이상) 레코드 2건을 "접경 화물집하장"행으로 심어둠 — **"비고"란에 수상하다는 티를 내지 않고, 오직 수량 비교로만 찾아내야 하는 방식**으로 설계(사용자 피드백: "노골적인 정답 유도는 지양"). 검색창+카테고리 필터로 "쌀"만 걸러보면 대비가 드러남. 담당자 이름은 전부 가상 도렌그라드풍 이름(다닐 보스코 등)으로 통일 — 한국어 실명이 섞여 있던 이전 버전 문제 수정함.
- **교차 단서(검색 ↔ ERP)**: 반출목록의 "출발지" 거래처명(센트럴철강, 그라노프 농산 등)을 이스크라 검색창에 치면 `HINTS` 배열의 업계 소식 기사가 뜸 — 대부분은 평범한 필러 기사지만, "그라노프 농산"만 "접경 인근 물류창고 추가 임대" 기사로 은근히 수상함을 암시(직접적 단정은 피함). 다른 거래처도 전부 결과가 있어야 "유일하게 그라노프만 결과가 뜸" 같은 메타적 티가 안 남.
- **팔레트:** 사용자 피드백으로 웜톤 크림+주황 조합을 버리고 **공신력 있는 검색엔진처럼 보이는 차분한 블루 계열**로 전면 교체(이스크라: `--accent:#1E5FC2` 계열, 라덴통상 ERP: 별도의 그래파이트+틸 `#3B6E71` 계열). **앞으로 만드는 UI도 이 방향(웜톤/애매한 주황 지양, 신뢰감 있는 톤) 유지할 것.**
- **인물 이미지 인종 다양성(확정 규칙, 뉘앙스 포함):** "모든 국가의 국민은 몽골로이드·흑인·백인·동남아시안 등이 기본적으로 섞여있어야 함" — A/B/C/D 어느 나라도 현실의 특정 인종과 1:1로 매칭되지 않음. 단, **매 사진마다 4개 인종을 전부 1:1:1:1로 억지로 다 넣으면 부자연스러움** — 사용자가 직접 수정 지시함("어느 사진엔 흑인·아시안, 어느 사진엔 백인이 있고 그런 느낌으로"). 즉 **개별 사진은 자연스럽게 2~3명 정도의 소규모 조합**(예: 이 사진은 흑인+동아시아인, 저 사진은 백인+동남아시안)으로 찍되, **여러 장의 사진을 모아놓고 봤을 때 전체적으로 다양한 인종이 고르게 등장**하도록 장면마다 조합을 다르게 가져갈 것. 군중·단체 사진(배급 대기줄, 모금 행사 등)을 Higgsfield로 생성할 때 프롬프트에 이 사진에서 보여줄 2~3개 인종 조합을 구체적으로 명시. 특정 이름 있는 개인 1인 초상(연예인 등)은 이 규칙 대상이 아니지만 특정 인종을 "디폴트"처럼 쓰지 않도록 유의.
- 클릭 가능한 요소는 전부 호버 시 실제 피드백(텍스트 링크 → 밑줄, 카드/행 → 연한 배경+보더)이 있고, 기능이 없는 장식 버튼(퀵링크 등)은 전부 제거함 — 이 원칙 계속 유지.
